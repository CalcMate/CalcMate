## Phase 2 — 계산기 자동화 고도화

> V1 운영본은 안정적으로 유지하면서 그 옆에서 Phase2를 개발한다.

### 목표

1. 계산기 자동 리라이트 파이프라인
2. Registry 완전자동화 (Single Source of Truth 확립)
3. 계산기 추가 자동화
4. /calculators/ 전체 목록 고도화
5. 인기/최신 계산기 자동 표시 기반 구축
6. 향후 Intent 기반 콘텐츠 허브를 연결할 수 있는 기반 마련

### 작업 순서 (현재 시점 가설 — P2-0 조사 결과에 따라 변경될 수 있음)

| 단계 | 내용 |
|------|------|
| P2-0 | Architecture & Registry Audit — 코드 수정 없이 현재 구조·의존관계 조사·문서화만 |
| P2-1 | Registry 완전자동화 |
| P2-2 | 계산기 추가 자동화 |
| P2-3 | 계산기 자동 리라이트 파이프라인 |
| P2-4 | /calculators/ 전체 목록 고도화 |
| P2-5 | 인기/최신 계산기 기반 구축 (실데이터 확보 후 활성화) |
| P2-6 | Intent 기반 콘텐츠 허브 연결 기반 마련 |

### Phase 2 운영 원칙

- 실제 사용자 데이터가 필요한 기능은 데이터 확보 전 활성화하지 않음
- 기존 코드 수정 전 현재 구조와 의존관계를 먼저 조사
- 조사 → 계획 → 승인 → 구현 → 테스트 순서 준수
- 한 번에 여러 구조를 변경하지 않고 단계별 진행

### Phase 2 금지사항

- V1 계산 로직 / UI / URL / slug 변경
- WordPress / GA4 구조 변경
- 실데이터 없이 인기순위 기능 활성화
- Intent 허브 본격 개발 (Phase 5까지 보류)

## Phase 3 이후 (개요)

| Phase | 내용 |
|-------|------|
| Phase 3 | 계산기 주 1~2개 추가 (7개 → 15개 → 20개+) |
| Phase 4 | GA4 + Search Console 실데이터 기반 인기/최신 계산기 자동 표시 |
| Phase 5 | WordPress V2 콘텐츠 허브 (Intent 기반 콘텐츠 → 계산기 유입) |
| Phase 6 | WordPress 하루 2개 자동 배포 파이프라인 |
| Phase 7 | 데이터→콘텐츠→사용자→데이터 자동화 순환 시스템 |

> Phase 3 이후의 세부 구현 내용은 확정되지 않았으며, 각 Phase 진입 시점에 별도 계획을 수립한다.
