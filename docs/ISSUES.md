## S5(고유정보) — 데이터 밀도와 직접 상관관계 없음 (반증됨)

- **상태**: 관찰 완료. 로직 미수정. Writer Layer v2에서 재검토.
- **결론**: **S5(고유정보) 점수는 registry/legal_master 데이터 밀도와 직접 상관관계가 확인되지 않음(반증).**
- **근거 (2026-07-11 A/B 실험, year-end-tax 한정)**:
  - 국세청·소득세법 교차검증 데이터(deduction_rules 5종 공제 + calculation_flow 7단계)를 legal_master에 넣고 writer 프롬프트에 주입.
  - 본문에 데이터 실제 반영됨(제137조 2회, 공제 5종 모두 언급).
  - 그럼에도 **S5 개별 점수: 30 → 20 (오히려 하락)**. 재현 종합점수 76 → 76(동일).
  - GPT 감점 사유: *"법적 근거 설명이 자연스럽고 계산 예시는 formula와 잘 맞으나, **설명이 가이드 수준을 벗어나지 못해 고유 정보가 적다**."*
  - → GPT는 **정확한 세법 수치도 '일반론/가이드'로 판정**하는 경향. "고유 정보"를 데이터 양이 아니라 '차별적 서술/관점'으로 해석.
- **부수 결과(구분)**: 같은 실험에서 **발행은 성공**(종합 76→81, WARN). 단 이는 S5가 아니라 **S4(문체) 등 다른 점수 상승** 덕분. 즉 데이터 반영이 발행을 도왔으나 S5를 올린 것은 아님.
- **만성성**: 발행된 7종 대부분이 S5 지적을 받음(연차 82/4대 80/실업 81/육아 86/연말정산 81 — 전부 S5 major). S5는 특정 계산기 문제가 아니라 **구조적으로 낮은 항목**.
- **재검토 방향(Writer Layer v2, 로직 미확정)**:
  1. `_score_with_gpt`의 S5 프롬프트 **"고유 정보" 기준 명확화**(무엇이 고유 정보인지 예시 제시).
  2. Prompt Manifest/Self Check에서 S5를 **"차별적 서술" 체크로 분해**.
  3. S5 **가중치/WARN 임계** 재검토(만성적으로 낮으므로 종합점수 왜곡 여부 점검).
- **관련 파일(참고, 미수정)**: `modules/publish_quality.py` `_score_with_gpt` (S5 프롬프트 228행).
