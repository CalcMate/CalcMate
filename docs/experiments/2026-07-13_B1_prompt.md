# 2026-07-13 · B-1 격리검증 프롬프트 (도입부 조항 위치 규칙)

## 목적
G8 법적근거 게이트 통과율 회복을 위해, "법령명+조항을 본문 초반(계산 원리 섹션 첫 문장)에 강제"하는
글로벌 규칙 블록을 writer 시스템 프롬프트에 추가. 퇴직금·육아휴직에서 forbidden_articles(제34조/제74조)
혼입과 조항 누락이 반복되던 문제를 다룸.

## 실제 사용한 블록 verbatim
> 위치: `prompts/calculator_writer_prompt.txt` **맨 끝 독립 블록**
> (`[출력 형식]` 블록 뒤, 선행 빈 줄 1개로 구분). 2026-07-13 기준 **미커밋 워킹트리 변경분.**

```text
[법령 조항 위치 규칙 — 필수]
- 법령명과 조항 번호(예: 고용보험법 제40조)를 '계산 원리' 섹션의 첫 문장에 먼저 정확히 명시한다.
- FAQ나 주의사항까지 미루지 말고, 본문 초반(전체의 앞 1/2 이내)에 조항을 최소 1회 정확히 표기한다.
```

## 이 블록이 writer에 도달하는 조립 순서
`modules/calculator_pipeline.py :: _write_article()`
```
system = _load_prompt()              # ← calculator_writer_prompt.txt (위 블록 포함)
       + _style_block(cfg)           # config AI_STYLE_BLOCKLIST
       + _legal_basis_block(calc)    # law/article/authority/writer_note/forbidden_articles/면책
       + _resolve_context_block(calc)
       + _rewrite_block(failed_rules)
```
- forbidden_articles는 `_legal_basis_block`에서 `- 다음 조항은 절대 인용하지 않는다: {…}` 로 주입.
- G8 판정은 `modules/publish_quality.py :: _check_g8()` — forbidden 문자열이 본문에 정규화 일치하면 critical.

## 참고
- 프로덕션 본문 생성은 `calculator_content_generator.generate_article`(PM 인라인 프롬프트)이 **아니라**
  `calculator_pipeline._write_article`(위 .txt 프롬프트) 경로다. 이 블록은 후자에만 영향.
- 재검증 하니스: `scripts/reverify_forbidden.py`
