## 2. 법적 근거 확정

### 병역법 제18조 실제 내용

`제18조(현역의 복무)` — 복무 방식 + 기준 복무기간 규정

- **제1항**: "현역에 복무하는 사람은 **입영한 날부터** 전역일까지 군부대에서 복무한다"
- **제2항**: 현역병 **기준 복무기간** (법문상 기간)

| 병종 | 제18조 제2항 법문상 기간 | 현행 실제 기간 |
|------|------|------|
| 육군 | 2년 (24개월) | 18개월 |
| 해병대 | 2년 (24개월) | 18개월 |
| 해군 | 2년 2개월 (26개월) | 20개월 |
| 공군 | 2년 3개월 (27개월) | 21개월 |

- **제3항**: 형 집행일수 · 군기교육일수 · 복무이탈일수 → 복무기간 미산입

> **중요**: 법문상 기간(24/26/27개월)과 실제 기간(18/20/21개월)이 다르다.
> 실제 기간은 제18조가 아닌 **제19조** 위임에 의한 국방부장관 고시·훈령으로 단축.

`제19조(현역 복무기간의 조정)` — 단축 권한 조항

- 제1항 제3호: "정원 조정의 경우 또는 병 지원율 저하로 복무기간의 조정이 필요한 경우에는 **6개월 이내에서 단축**"

### 병역법 제26조 실제 내용

`제26조(사회복무요원의 소집)` — **소집 절차·기관 배정** 규정

- 복무기간 규정 없음 (소집 절차만)
- **→ 사전검증 보고서의 "병역법 제26조" 인용은 오류.**

### 사회복무요원 복무기간 실제 근거

`제30조 제1항(사회복무요원의 복무기간)` — 법문: "사회복무요원의 복무기간은 **2년 2개월**로 한다"

## 3. 계산식 확정

### "입대일 + N개월 - 1일" 공식 출처 확인 여부

| 조사 대상 | 결과 |
|---|---|
| 병무청 홈페이지 공식 문서 | **미확인** — 전역일 산식 명시 없음 |
| 법령 (병역법·시행령) | **미명시** — "복무기간이 끝나는 날" 표현만 존재 |
| 더캠프(THE CAMP, thecamp.ai) | 사용하나 **민간 사기업**(Kakao) — 병무청 공식 서비스 아님 |
| 민간 계산 서비스 다수 | 공통 사용 확인 — **관행 계산식** |

**→ 공식 출처 미확인 — 민간 관행상 계산식**

병역법 제18조 제1항의 "입영한 날부터" 문언이 입영일 포함의 법적 근거가 될 수 있으나,
전역일 산식("–1일") 자체는 법령에 명시 없다.

### 날짜 연산 예외 규칙

| 항목 | 확인 결과 | 공식 근거 |
|---|---|---|
| 월말 입영일 + 개월 가산 처리 | 민법 제160조: 기간을 월로 정한 때 말일 = 그 달 마지막 날 | 민법 (간접) |
| 2월 28일/29일(윤년) 입영 처리 | 민법 제160조 동일 적용 | 민법 (간접) |
| 입영일 포함 여부 | 병역법 제18조 제1항: "입영한 날부터" → **포함** | 병역법 (직접) |
| 전역일 포함/제외 여부 | 법령 미명시. 관행상 포함 | **없음** |
| 복무기간 단축(정책 변경) | 병역법 제19조 위임 — 고시로 변경 가능 | 있음 (변동성) |
| 군기교육·복무이탈 미산입 | 병역법 제18조 제3항 명시 | 있음 (계산기 적용 불가) |
| 복무 중단·개인 휴가 | 개인별 상이. 계산기 범위 외 | **없음** |

공식 근거 없는 항목에 대한 **후보 방안** (결정 보류):

- **방안 A (통념 적용 + 면책 문구)**: "입대일 + N개월 - 1일" 관행 공식 적용, 결과 페이지에 "본 계산 결과는 참고용이며 실제 전역일은 병무청 확인 필요" 면책 문구 삽입
- **방안 B (면책 범위 확장)**: 군기교육·이탈·질병 등 개인 사정 반영 불가 명시, 스코프 제외 조건에 명시적 포함
