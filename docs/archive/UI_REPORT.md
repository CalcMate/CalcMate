## 1. 변경 전

- 단순 탭 나열 구조: 현황 / 발행 목록 / 오류 로그 / 비용 모니터 / (전략회의실) / 설정 / 헬스체크 / 실시간 로그
- 홈/대시보드 진입 시 전체 상태를 한눈에 보기 어려움(탭마다 이동 필요)
- 비용 모니터 = 플레이스홀더, 오류 로그 = `get_sheet` 미정의로 동작 불가(※ 이전 단계에서 1차 수정)
- 발행은 `DAILY_POST_COUNT` + `RUN_INTERVAL_HOURS`(간격 반복) 중심 — 발행 시각 지정 불가
- 1클릭 작업 실행 수단 없음, 실시간 로그 수동 새로고침

## 2. 변경 후

사이드바 메뉴(운영 흐름 순 재배치):
`🏠 운영센터` · `📋 작업 보드` · `📅 오늘 발행 일정` · `🌐 사이트 관리` · `💰 비용 모니터` · `⚠️ 오류 로그` · `🏥 헬스체크` · `📡 실시간 로그` · `📊 현황` · `📋 발행 목록` · `🧠 전략회의실` · `🔧 설정`

### 🏠 운영센터 (홈, 기본 화면)
- **⚡ 빠른 실행 패널(상단 고정)** — 7버튼: 즉시 발행 · 파이프라인 1회 · 발행 1건 · 이미지 재생성 · 전략회의실 · 헬스체크 · 백업 생성
- **KPI 카드** — 오늘 목표 / 발행 완료 / 대기중 / 실패 / 다음 예약 시간
- **AI 비용** — 오늘 / 이번달
- **서비스 상태** — OpenAI·Claude·Gemini·Sheets·Drive·WordPress (마지막 헬스체크 캐시, 🟢/🔴)
- **최근 오류 5건** — pipeline.log 기반
- **오늘 일정 요약** — 예약/완료/대기/실패
- 모두 로컬 파일만 읽어 **빠르게 로딩**(5초 목표)

### 📋 작업 보드 (칸반)
- 6열: 수집중 → 작성중 → 검수중 → 발행대기 → 발행완료 / 오류 (상태값 기준 자동 분류, 건수+제목)

### 📅 오늘 발행 일정 (스케줄 통합)
- 오늘 일정 표(예약/실제/지연/상태/결과) + 진행률
- 버튼: **스케줄 생성 · 재생성 · 오늘 일정 초기화 · ⚡즉시 발행**
- **슬롯 설정**: 평일/주말 분리, **슬롯 수 = 하루 발행 개수**(DAILY_POST_COUNT 자동), 실패 처리 모드 3종, 검증(시작<종료/개수/형식/겹침/빈 슬롯)

### 기타 강화
- **💰 비용 모니터**: 오늘/월/누적, Provider별(차트)·모델별, 토큰
- **⚠️ 오류 로그**: DB logs 조회 표(발생시간/실패단계/오류내용/건수)
- **🏥 헬스체크**: 카드형(정상🟢/오류🔴 강조), 캐시 표시 + 실시간 재검사
- **📡 실시간 로그**: `st.fragment(run_every=5)` 자동 갱신(토글)
- **🔧 설정**: 발행 방식 라디오(예약 발행 / Legacy 반복), DAILY_POST_COUNT는 슬롯 수로 자동 결정 표시

## 4. 사용 방법

1. **대시보드 실행**: `scripts/run_dashboard.bat` 더블클릭 → 브라우저에서 운영센터 표시
2. **발행 일정 만들기**: `📅 오늘 발행 일정` → 슬롯 수/시간 설정 → `슬롯 설정 저장` → `스케줄 생성`
3. **자동 운영 시작**: `scripts/run_scheduler.bat` 실행(예약 발행 모드) → 예약 시각마다 1건 자동 발행
   - Legacy 간격 반복을 원하면 설정에서 'Legacy 반복 실행 모드' 선택 후 `scripts/run_schedule.bat`
   - 단발 테스트는 `scripts/run_pipeline.bat`(= `--once`)
4. **즉시 발행**: 운영센터/일정 탭의 `⚡ 즉시 발행` → 확인창에서 모드 선택 → 예
5. **사이트/계산기 추가**: `🌐 사이트 관리` → `➕ 사이트 추가`
6. **상태 점검**: `🏠 운영센터`에서 KPI·비용·서비스 상태·최근 오류 한 화면 확인

## 5. 제약/주의
- 빠른 실행의 발행 계열(즉시발행/파이프라인/발행1건)은 **Google Sheet 접근이 필요** — 현재 서비스 계정 권한(403) 복구 전에는 오류 메시지 표시(코드 정상).
- 서비스 상태는 **마지막 헬스체크 결과 캐시**(즉시성 위해). 최신 상태는 '헬스체크' 버튼/탭에서 재검사.
- `finance`/`affiliate` 유형 사이트는 수집기 stub이라 수집 0건(UI에 안내).
