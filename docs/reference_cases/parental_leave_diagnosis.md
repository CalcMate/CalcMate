## 1. 설계 범위 규정 + 제도 기준일

### 설계 범위 (현재)
- **slug**: `육아휴직_급여_계산기`
- **현재 입력**: `avg_monthly_wage`, `leave_months`, `government_support_percentage`, `company_policy_support_percentage`
- **현재 출력**: `total_leave_allowance`
- **현재 공식**: `avg_monthly_wage × leave_months × (gov_pct + company_pct) / 100`

### 제도 기준일 — 코드 기준
- `law_version: "2026-07"` (index.html SM_CONFIG)
- `last_verified: 2026-07-05` (legal_basis.draft.yaml)
- **그러나 실제 계산식은 어떤 제도 기준도 따르지 않음** — 법령과 무관한 임의 구조

### 올바른 설계 범위 (권고)
**예상 월 육아휴직급여 계산기**
- 입력: 월 통상임금, 특례 적용 여부(일반/6+6), 특례 적용 월(1~6)
- 법령: 고용보험법 제70조, 시행령 제95조
- 제도 기준일: 2024년 1월 1일 (6+6 특례 시행)

## 2. 지급률 구간 계단 구조 전체 대조표

### [ 일반 육아휴직급여 ]
고용보험법 제70조 + 시행령 제95조 (사후지급금 폐지 이후 2022년 3월~)

| 기간 | 지급률 | 상한 | 하한 |
|------|--------|------|------|
| 전 기간 (1~12개월) | 통상임금 × 80% | 월 150만원 | 월 70만원 |

**하한 적용 분기**: 통상임금 × 80% < 70만원 → 70만원 고정  
**상한 적용 분기**: 통상임금 × 80% > 150만원 → 150만원 고정  
**하한 경계 통상임금**: 875,000원 (× 80% = 700,000원 = 하한)  
**상한 경계 통상임금**: 1,875,000원 (× 80% = 1,500,000원 = 상한)

### [ 6+6 부모 육아휴직 특례 ]

## 3. 특례 우선순위 규칙

**일반 vs 6+6 특례: 배타적 (동시 적용 불가)**

| 조건 | 적용 제도 |
|------|-----------|
| 부모 중 한 명만 육아휴직 | 일반 육아휴직급여 (80%, 상한 150만) |
| 부모 모두 육아휴직 + 생후 18개월 이내 | 6+6 특례 우선 (1~6개월: 100%, 단계적 상한) |
| 6+6 특례 7개월 이후 | 일반으로 자동 전환 (80%, 상한 150만) |

**구 3+3 특례 (2022년 1월~2023년 12월):**
- 생후 12개월 이내, 부모 모두 육아휴직, 첫 3개월
- 2024년 1월 6+6으로 완전 대체 → 현재 계산기 불필요

**우선순위 적용 로직 (권고 구현 방향):**
```
if (is_66_eligible && month_idx <= 6) {
    급여 = min(monthly_wage, PL_66_CAP[month_idx])   // 100%
} else {
    급여 = min(max(monthly_wage * 0.8, 700_000), 1_500_000)  // 일반
}
```

## 4. 제70조 재검증 결과 (SP-2 후속)

| 항목 | 결과 |
|------|------|
| 고용보험법 제70조 적용 여부 | ✅ legal_basis에 명시, FAQ[4]에 인용 |
| 제70조 내용 대응 | ✅ 30일 이상 + 피보험단위기간 180일 → 급여 지급 |
| 금지 조항 제40조 잔존 | ✅ 0건 |
| 금지 조항 근로기준법 제74조 잔존 | ✅ 0건 |
| 시행령 제95조 (지급액 기준) | ❌ legal_basis 미언급, 계산기 미반영 |
| 180일 요건 FAQ/article 언급 | ❌ 전혀 없음 |

**SP-2 재검증 결론**: 제70조 인용 자체는 맞으나, **실제 지급액 산정 근거(시행령 제95조)가 없고 계산식이 법령과 무관**하므로 사실상 제70조 검증 의미가 없는 상태.

## 11. 수정 방향 제안

### Phase 1 — Critical 오류 (법령/콘텐츠)
- PL-3: FAQ[0] 자녀 연령 교정 (만 8세 이하)
- PL-4: FAQ[1] 수급 요건 교정 (180일 + 원칙-예외 구조)
- PL-5: FAQ[6] 육아휴직 권리 교정 (남녀고용평등법 제19조)
- PL-6: FAQ[2] 코드 문자열 제거 + 설명 교정

### Phase 2 — 계산식 재설계 (가장 복잡)
계산기 **전면 재설계** 필요:

**권고 입력 구조:**
- `monthly_wage`: 월 통상임금 (원)
- `use_66_special`: 6+6 특례 적용 여부 (0/1 또는 체크박스)
- `special_month`: 특례 적용 월 (1~6, 특례 미적용 시 무시)

**권고 출력:**
- `monthly_allowance`: 예상 월 육아휴직급여
- `_formula`: "통상임금 N원 × 80% = M원 (상한 150만원 적용)" 또는 "6+6 특례 N개월: 통상임금 N원 × 100% = M원 (상한 X만원 적용)"
- `notices`: 피보험단위기간 180일 안내

### Phase 3 — 표준 적용
- PL-9: 입력 검증 (AL-1 패턴)
- PL-10: notices
- PL-11: _formula
- PL-12: 180일 경계 처리
- C-13: 원칙-예외 3곳 일관성
