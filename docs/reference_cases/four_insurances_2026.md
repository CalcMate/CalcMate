## 장기요양보험 계산 순서 (핵심 주의사항)

```
올바른 계산:
  health_insurance = monthly_salary × 0.03545
  long_term_care   = health_insurance × 0.1296   ← 건강보험료에 곱

절대 금지:
  long_term_care = monthly_salary × 0.1296        ← 급여에 직접 곱 (375,017원 과다 오류)
```

300만원 기준:
- 올바른 장기요양: 106,350원 × 12.96% = **13,783원**
- 잘못된 계산:  3,000,000원 × 12.96% = **388,800원** (375,017원 과다)

이 계산 순서는 `test_ltc_order_must_use_health_insurance` 테스트로 영구 보호됩니다.

## 내부 합계 보장 (FI-3 회귀 안전망)

모든 케이스에서 다음이 성립합니다:

```
total == national_pension + health_insurance + long_term_care + employment_insurance
```

`test_total_equals_sum_all_cases` (8케이스 parametrize)가 영구적으로 이 불변식을 보호합니다.
향후 보험 종목 추가 또는 계산식 변경 시, total 미반영 시 자동 실패합니다.
