# RMS 정기 점검 스케줄러 설정 (Windows Task Scheduler)

## 개요
이 문서는 매년 정기적으로 `scripts/rms_annual_check.py`를 실행하여 RMS 법령 변경 사항을 점검하고 회귀 테스트를 수행하기 위한 Windows 작업 스케줄러 설정 절차를 안내합니다.

## 설정 절차

1.  **작업 스케줄러 열기:**
    - Windows 검색창에 "작업 스케줄러"를 입력하여 실행합니다.
2.  **작업 만들기:**
    - 우측 작업 패널에서 "작업 만들기"를 클릭합니다.
3.  **일반 탭:**
    - 이름: `RMS 정기 점검`
    - "사용자가 로그온할 때만 실행" 또는 "사용자가 로그온하지 않아도 실행" 중 선택 (보안상 후자 권장, 단 암호 저장 필요).
    - "가장 높은 수준의 권한으로 실행" 체크.
4.  **트리거 탭:**
    - "새로 만들기" 클릭.
    - 작업 시작: "예정된 시간"
    - 설정: "매년", 시작 날짜를 12월 1일로 설정.
5.  **동작 탭:**
    - "새로 만들기" 클릭.
    - 프로그램/스크립트: `C:\Users\연수\Desktop\블로그자동_v12\run_scheduled_check.bat` (절대 경로)
    - 시작 위치 (선택): `C:\Users\연수\Desktop\블로그자동_v12\`
6.  **설정 탭 (권장):**
    - "실패 시 다음 간격으로 다시 시작": 1시간
    - "재시도 횟수": 3회

## 주의사항
- 실제 작업 스케줄러 등록 및 트리거 테스트는 사용자가 직접 수행해야 합니다.
- 배치 파일(`run_scheduled_check.bat`)이 프로젝트 경로에 위치해야 합니다.
